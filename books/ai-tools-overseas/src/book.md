# 前言

这本书把一条可以长期维护的路径讲清楚：从网络环境、海外手机号、Gmail，到 ChatGPT、Claude、Grok、Gemini 的注册登录，以及各家开发工具 Codex、Claude Code、Cursor、Antigravity，再到 Apple App Store、Google Play 和银行卡的订阅支付。目标不是「一次注册成功」，而是让每个账号的关系清楚、可恢复、可管理。

全书的前提只有一条：**使用真实资料，并由本人长期控制**手机号、恢复邮箱、Apple ID、Google 账号和支付卡。地区、手机号和支付方式必须符合对应平台当时的规则。社交平台上的个人经验只作为线索，最终以服务商、App Store 和 Google Play 的当前官方页面为准。

:::warn 合规提示
请遵守所在地法律法规与各平台服务条款。本书不提供、也不鼓励伪造地区、地址、身份或付款资料；网络可达不等于具备平台要求的地区资格。各平台规则会变化，文中描述以作者核对时的官方页面为依据（底稿核对时间 2026-10-10），操作前请以官方页面为准。
:::

本书不标注任何价格，不放二维码；文中出现的手机号、卡号、邮箱、地址和端点均为示意，请勿照抄。

## 02 网络环境：XConnect 三端

部分境外网站和服务在中国大陆网络环境下存在访问限制。注册前，先准备一个稳定、本人可控、符合所在地适用法律和服务条款的网络访问路径。本书以 XConnect 作为网络访问入口。

:::warn
网络可达只是注册前提，不能替代服务商的地区要求、手机号验证、实名验证或支付审核。
:::

[[fig:xconnect]]

### 2.1 下载与注册

1. 打开 XWorkTech 下载页（xworktech.com/download），按设备系统下载对应版本的 XConnect；
2. 安装后打开应用，阅读应用权限和服务条款；
3. 没有账号时进入控制台注册页（示意：console.xxx.example.com/register），填写用户名、邮箱、密码和确认密码，再提交邮箱验证码完成注册；
4. 注册完成后，控制台会为账号分配一个全局唯一 UUID，可在用户中心查看。

页面当前要求：用户名 4–16 位字母或数字、以字母开头，密码至少 8 位。界面和规则可能随版本变化，以页面显示为准。不要把密码、邮箱验证码或 UUID 发布到公开文档、截图或聊天群。

### 2.2 配置连接器

如果应用还没有连接配置，进入「连接器」，选择自托管连接器或新增连接，按控制台提供的资料填写工作区端点、账号标识、密码和连接名称（可用 `jp`、`ph`、`sg`、`us` 等便于识别的名称），然后点击「连接账号」。

### 2.3 三端连接

:::table
端 | 操作要点 | 成功标志
iOS | 首页选择节点 → 开始连接 | 状态由「连接中」变为「已连接」，显示节点、时长和延迟
Android | 登录后选择节点 → 开始连接 → 保持后台运行 | 显示连接时长、位置和延迟
Desktop（macOS / Windows / Linux） | 「连接器」确认端点与配置 → 开始连接 | 首页由「已断开」变为「已连接」
:::

### 2.4 连接后的验证

1. 打开一个普通网页，确认网络访问正常；
2. 打开 Google 或 Gmail，确认页面和登录入口正常；
3. 打开 ChatGPT、Claude、X 或 Grok，确认服务页面可访问；
4. 注册或订阅过程中保持当前连接，不要频繁切换节点；
5. 不再使用时点击「断开连接」。

「已连接」代表客户端网络连接已经建立，不代表任何平台一定会通过地区、手机号、身份和付款审核。

## 03 手机号选择

注册需要一个海外手机号：实体卡、eSIM、虚拟号都可以用来收验证码，但它们的长期可靠性差别很大。手机号一旦被回收，绑定在上面的账号可能无法恢复。

[[fig:phone]]

### 3.1 首选：实体海外手机卡

优先选择支持短信和 Pay as you go 充值的海外实体卡。重点检查：能接收国际服务的验证码短信；支持在线充值或低额保号；长时间不使用不会立即回收号码；能查看余额与有效期；SIM 卡由本人长期持有，换手机后仍可使用。

### 3.2 次选：支持短信的海外 eSIM

例如菲律宾 DITO eSIM（详见第 11 章）。购买前确认具体套餐支持 **SMS 短信**——有些 eSIM 只有数据流量，不能接收验证码。还要确认：是否真的提供手机号；是否支持入站短信；能否续费；停机后能否恢复；是否需要实名；在漫游状态下能否接收短信。

### 3.3 最后备用：虚拟短信号码

海外短信虚拟号码平台只能作为临时注册或测试备用，不适合绑定重要账号：号码可能被回收或重新分配；可能无法再次收到恢复短信；同一号码可能被多人使用过；平台可能拒绝虚拟号段；不能稳定支持支付验证和账号找回。

:::tip
如果必须使用虚拟号码，完成注册后应尽快在账号安全设置中替换为本人长期控制的手机号，并补充恢复邮箱、双因素认证和恢复码。
:::

## 04 账号与恢复资料

恢复邮箱和手机号不是一次性注册材料。只要账号还在使用，就应保持可访问、可续费、可验证。

[[fig:recovery]]

:::table
资料 | 用途 | 要求
Gmail 主邮箱 | 注册 ChatGPT、Claude 等服务 | 本人控制，能够长期收信
恢复邮箱 | 找回 Gmail、AI 服务和支付账号 | 不与主账号使用同一恢复链路
海外手机号 | 注册、短信验证、账号恢复 | 本人长期持有，可续费保号

# 中篇 注册

## 05 Gmail

Gmail 是后续 ChatGPT、Claude、Google Play 和支付通知的核心恢复入口，不要使用临时或一次性邮箱。

[[fig:gmail]]

### 5.1 注册步骤

1. 通过稳定网络打开 Google Account 注册页面；
2. 选择个人用途，填写真实姓名、出生日期等资料；
3. 选择 Gmail 地址并设置独立密码；
4. 如页面要求手机号验证，使用本人长期控制的海外手机号；
5. 绑定恢复邮箱，登录 Gmail 确认可以收发邮件；
6. 在安全设置中开启双因素认证，保存恢复码，并在另一台可信设备上测试登录。

Google 官方说明，注册或登录时有时会要求手机验证，并会限制一个手机号可以创建的账号数量。

### 5.2 注册后检查

主邮箱能收信；恢复邮箱能收到安全通知；手机号显示为已验证；双因素认证已开启；恢复码已保存；没有把验证码、密码或恢复码发给任何人。

## 06 ChatGPT

[[fig:chatgpt]]

### 6.1 注册方式

1. 打开 ChatGPT 官方网站、手机 App 或桌面客户端，选择使用 Google 账号继续；
2. 使用准备好的 Gmail 完成登录；
3. 如触发手机号验证，使用本人长期控制的海外手机号；
4. 登录后在账号设置中开启多因素认证（若页面提供）；
5. 先使用免费功能确认账号稳定，再决定是否订阅。

底稿核对时，菲律宾在 OpenAI 公布的 ChatGPT 支持地区列表中；支持地区会调整，以官方列表为准。

### 6.2 订阅路径

网页订阅由 ChatGPT 网页账单管理；iPhone / iPad 订阅由 Apple App Store 管理；Android 订阅由 Google Play 管理。OpenAI 说明，商店订阅必须在对应商店账号中管理，卸载应用不会自动取消订阅。ChatGPT 订阅与 API 账单是不同路径，不要混为一项。

### 6.3 桌面端

从 ChatGPT 官方网站下载桌面客户端，安装后使用与网页 / 手机 App 相同的账号登录；订阅权益随账号同步。具体支持的操作系统和版本以官方下载页为准。

### 6.4 开发工具：Codex

Codex 是 OpenAI 面向编程场景的开发工具。登录方式以官方说明为准，通常可使用 ChatGPT 账号（权益随订阅计划而定）或 API 账号；两者属于不同计费路径。请从 OpenAI 官方网站或官方文档获取，支持的终端（如命令行、IDE 扩展、桌面应用等）以官方页面为准。

:::warn 安全边界
开发工具可能读写项目文件或执行终端命令。不要把密码、恢复码、API Token、私钥、`.env` 文件或支付资料放入可访问的工作区。
:::

## 09 Gemini 与 Antigravity

Gemini 和 Antigravity 都使用 Google 账号登录，不需要另建一套独立账号体系。

[[fig:gemini]]

### 9.1 Gemini

1. 使用本人长期控制的 Google 账号，在网页、手机 App 或桌面端打开 Gemini；
2. 检查当前账号实际显示的功能和地区可用性；
3. 确认恢复邮箱、长期手机号和双因素认证仍然可用；
4. 先用免费功能测试实际需要的能力；
5. 如页面提供 Google AI 计划，查看计划名称、适用地区、账单周期和付款账号；
6. 订阅后在 Google 账号或 Google Play 的「付款和订阅」中核对订单与续费日期。

「能打开 Gemini」不等于每个模型、移动端功能或付费计划都可用，以登录后页面实际显示为准。

### 9.2 开发工具：Antigravity

Antigravity 是 Google 的 agent-first 开发平台，包含桌面应用、IDE / 编辑器集成、CLI 和 SDK。官方入门文档显示，可以使用个人 Google Account 登录，也可以连接 Gemini Enterprise 的 Business account。

1. 从官方下载页获取，支持的操作系统以官方页面为准；
2. 启动后用本人 Google Account 登录，企业用户按组织要求选择；
3. 创建 Project，用「添加文件夹」关联本地工作区或 Git 仓库；
4. 首次运行任务前，检查项目范围、读写权限、终端命令和浏览器访问权限；
5. 让 Agent 先生成计划或 Artifact，确认后再执行写文件、测试、提交等动作。

:::warn 安全边界
Agent 可能访问项目文件、执行终端命令或使用浏览器。不要把密码、恢复码、API Token、私钥、`.env` 文件或支付资料放入可访问的工作区；不要使用来源不明的安装脚本、破解版本或共享账号。

Gemini 聊天、Antigravity 的 Agent 额度、Google Cloud API 用量可能属于不同计费路径。付款前确认：账号是否正确；购买的是哪类计划；入口是 Google One、Google Play、Google Cloud 还是组织管理员；自动续费与取消入口在哪里。

4. 按 App 内指引充值，开通 Maya 虚拟 Visa 卡；
5. 在服务商官网 / 网页的账单页直接填写虚拟卡信息完成订阅；
6. 记录每个订阅的扣款平台、续费日期和取消入口。

### 11.3 可选：用在应用内订阅

如果更习惯在手机 App 内订阅，可参考第 12、13 章。底稿核对时的官方信息：Google Play 菲律宾区官方支持 PayMaya / Maya 钱包付款（要求账户已注册且余额充足）；Apple 公布的菲律宾 Apple Pay 发卡机构列表中未显示 Maya。应用内订阅以商店付款页面实际显示为准。

:::warn
作者实测结果只代表个人使用经验，不代表所有账号、地区和时间都适用。不要使用他人的 Maya 账户、银行卡、身份证明或验证码；不要为付款修改虚假的地区、地址或账单资料。
:::

## 13 Google Play 订阅（可选）

主路线是官网 / 网页直接填卡（第 10、11 章）。只有需要在 Android App 内订阅时，才需要本章。

[[fig:play]]

1. 使用本人 Gmail 登录 Google Play；
2. 确认 Play 国家/地区与实际所在地、支付资料一致；
3. 添加本人付款方式，或在菲律宾 Play 区添加已注册且有余额的 Maya 钱包；
4. 在目标 Android 应用中选择订阅，付款前确认是正确的 Google 账号；

## 附录 常见问题排查与案例

[[fig:trouble]]

### 收不到验证码

依次检查：国家区号是否正确；SIM / eSIM 是否真的支持短信；运营商是否允许国际短信漫游；号码是否已被使用过多次；短信是否延迟；是否短时间内重复请求过多；能否改用邮箱验证或官方恢复流程。重要账号应换成本人长期控制的实体卡或短信 eSIM。

### 付款失败

:::table
平台 | 检查项
Google Play | Play 地区与支付资料是否一致；登录账号是否正确；Maya 是否完成验证、余额是否充足；Visa 是否允许境外线上交易与 3-D Secure；订阅是否已存在于另一个账号
App Store | Apple ID 地区与付款方式是否匹配；账单地址是否准确；银行是否允许境外数字内容交易；是否有重复订阅或未完成的付款问题
网页订阅 | 账号和实际使用地区是否在官方支持范围内——能否付款不只看银行卡是哪国的
:::

### 重复扣款

同一服务可能分别在网页、App Store 和 Google Play 上产生独立订阅。先看扣款收据确认实际付款平台，再到对应平台取消。

### 网页打不开

先判断问题出在哪一段，不要一上来就重装软件。通用顺序：重启路由器 → 修改 DNS → 刷新 DNS 缓存 → 重启浏览器 → 无痕窗口 → 换手机热点对比。同时检查系统代理、PAC 自动配置脚本和安全软件状态。

:::table
现象 | 大概率原因
公司网络打不开，手机热点能打开 | 公司出口、VPN 或防火墙策略
所有网络都打不开 | 本机代理、DNS、浏览器或安全软件
一个运营商宽带正常，另一个改 DNS 仍不行 | 运营商线路、IPv6、CDN 节点或解析问题
页面能打开，登录后才报错 | 账号或组织策略问题
只有某一个网站不通 | 该网站的访问策略或网站自身故障
:::

### 案例：公司电脑打不开 NotebookLM

**现象**：Windows 公司电脑访问 NotebookLM，提示「无法访问此页面」。这更像网络链路问题：企业出口策略拦截、系统代理或 PAC 转发到不可用代理、公司 DNS 过滤、Workspace 组织策略禁用（通常是能打开、登录后才报错）或企业浏览器策略。先换手机热点试一次；公司电脑应优先联系公司 IT。

### 案例：联通宽带能打开，移动宽带打不开

可能是运营商线路、IPv6、CDN 节点分配或路由问题，也可能是网站限制了该网络，改 DNS 不一定能解决。临时办法是换网络或手机热点。

### 案例：用海外银行卡订阅 ChatGPT 付款失败

能否付款主要取决于账号和实际使用地区是否在官方支持范围内，而不只是银行卡是哪国的。请对照官方支持地区列表，并按第 03、10 章准备手机号与付款方式。
