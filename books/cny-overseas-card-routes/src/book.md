# 前言

这份攻略只回答一个问题：**人民币怎么进到海外卡，海外卡里的钱怎么回到人民币。** 三条路线各有一个绕不开的前提：

1. **香港**：入金最容易，但通常要本人去一趟香港开户；汇回内地有限制：目前已知中银同名账户可行，待验证；
2. **菲律宾**：靠一张能收短信的 eSIM（作者用的是 DITO eSIM + Maya）；
3. **美国 Mercury（水星）**：靠先注册一家海外 LLC，它是公司账户，不是个人账户。

:::warn 合规提示
本文是个人经历分享加官方公开资料整理，**不构成法律、税务或投资意见**。额度、费率、开户条件随时变化，文中凡未注明官方依据的数字一律 **以官方最新为准**。请使用真实资料、本人账户，遵守外汇管理与各平台规则。文中不含任何账号、卡号或证件号。
:::

# 上篇 三条路线

## 01 先看全局

[[fig:overview]]

三条路线不是互相替代，而是分工：香港负责人民币进出，Mercury 负责公司美元收入，Maya 负责小额海外订阅。

## 02 香港：入金最容易，但要本人去一趟，回流有限制

### 2.1 能做什么

- **¥ → 卡**：内地本人银行卡购汇后跨境汇款到本人名下香港账户。
- **卡 → ¥**：从香港账户汇回内地本人账户 **有限制：目前已知中银同名账户可行，待验证**；其他银行通道暂无实测，以银行最新为准。
- 常见选择：中银香港、汇丰（HSBC）、ZA Bank 等虚拟银行。具体开户条件、是否支持线上开户、最低存款要求 **以各银行官方最新为准**。

### 2.2 前提条件

1. 内地居民身份证；
2. 港澳通行证（部分银行会核对入境记录）；
3. 地址证明（如近期账单、银行对账单，具体类型以银行要求为准）；
4. 通常需要 **本人赴港** 办理；部分虚拟银行支持线上开户，但资格限制较多。

### 2.3 额度规则（来自作者《出海第一步》资金合规章，汇发〔2020〕14号）

- 个人购汇年度便利化额度为 **等值 5 万美元**，按自然年计算；
- 购汇须如实申报用途，不得用于尚未开放的资本项目（如境外证券、境外房产）；
- 超出年度额度的经常项目购汇，凭交易真实性材料办理；
- 个人单日汇出超等值 5 万美元，需提供交易相关材料。

### 2.4 香港段要注意的事

- HKMA 反洗钱指引要求银行做客户尽职调查，含港币 8,000 元及以上电汇的信息要求；银行可核查资金来源与汇款用途；
- 香港金融机构按 CRS 申报内地税务居民账户，并交换至内地；
- 汇丰网上理财办理国际电汇的一般步骤与填写提示：见 **细节专题第 06 章**；用途声明、证明材料、限额与费用仍 **待向汇丰核实，以银行最新为准**。

:::tip 一句话
只要愿意去一趟香港，香港账户就是整套资金路线的枢纽。注意回流内地有限制：目前已知中银同名账户可行，待验证。
:::

## 03 菲律宾：靠一张能收短信的 eSIM

### 3.1 作者路线：DITO eSIM + Maya

[[fig:ph]]

DITO eSIM 的作用是提供 **本人长期控制的菲律宾手机号**，用于 Maya 注册和验证短信。购买前确认（摘自作者《海外 AI 服务访问指南》）：

- 套餐真的提供 **SMS 短信**，不是纯流量 eSIM；
- 号码能接收国际验证码；
- 支持充值和续费保号，并记录号码有效期和下一次充值日期；
- 手机支持该 eSIM 的频段和配置。

### 3.2 Maya / GCash 开户顺序

1. 用本人菲律宾手机号注册 Maya（GCash 同理）；
2. 用真实身份资料完成 KYC（通常需要护照，部分功能可能要求菲律宾本地证件，**以官方最新为准**）；
3. 设置独立密码和应用安全验证；
4. 小额充值，测试余额、付款和退款记录；
5. 用 Maya 虚拟 Visa 在官网直接订阅 AI 服务（作者实测），或在菲律宾区 Google Play 添加 PayMaya（Google 官方支持）。

### 3.3 钱怎么进、怎么出

- **¥ → Maya**：没有正规的人民币直达通道，一般经 **香港账户或 Wise** 中转后入金；可用入金方式 **以 Maya 官方最新为准**。
- **Maya → ¥**：同样难，通常也要经香港或 Wise 这类中转。
- **额度**：钱包账户额度与 KYC 等级挂钩，整体偏低，具体数字 **以官方最新为准**。

:::warn 别踩的坑
不要使用他人的 Maya 账户、证件或验证码；号码一旦被回收，绑定的账号可能无法恢复。Apple 官方菲律宾 Apple Pay 发卡机构列表中没有 Maya，别把它当 App Store 的稳定支付方式。
:::

## 04 美国 Mercury：靠先注册一家 LLC

### 4.1 前提链路

[[fig:us]]

Mercury 是 **公司账户**。作者实际走过的顺序（摘自《出海第一步 · 一人公司合规全流程》）：

1. **美国 LLC 设立**：作者通过 doola 设立 Wyoming LLC，拿到成立文件与运营协议；
2. **EIN 与 147C**：服务商协助提交 SS-4；作者从成立到拿到 147C 确认函约 64 天；
3. **Mercury 开户材料**：公司成立文件、EIN 证明（如 147C）、受益所有人身份证明、**真实经营地址**、业务与资金来源资料；
4. 账户建立（Checking / Savings）后，再完成首笔入金。

### 4.2 钱怎么进：只走本人香港户

- 从 **本人香港个人账户** 向 LLC 的 Mercury 账户做 **成员出资（capital contribution）**，Mercury 书面答复确认支持，个人户名与公司名不同不影响；
- 电汇信息按 Mercury 后台当时显示的最新 International Wire Details 填写；美国境内付款可用 ACH；
- 从汇丰香港网上理财发起国际电汇时，操作步骤与字段说明见 **细节专题第 06 章**；
- 不把 Visa 卡当充值入口；
- 留存公司所有权证明、出资记录、电汇回单，以备事后审核。

### 4.3 钱怎么出：回到人民币

LLC 账户 → **分红 / 利润分配** → 本人香港个人户 → 汇回内地本人账户（有限制：目前已知中银同名账户可行，待验证）。

:::warn 红线
**中国大陆个人账户 ↔ 海外公户（LLC 账户），双向都不直接走。** 只走本人香港个人户 ↔ LLC 账户，渠道只有成员出资（个人 → 公司）和分红 / 利润分配（公司 → 个人）。外国人全资单成员 LLC 需提交 Form 5472 + pro-forma 1120，出资和分配属于需申报交易；税务处理请咨询专业人士。
:::

# 下篇 怎么组合

## 05 推荐组合

[[fig:combo]]

- **香港 = 人民币枢纽**：人民币进出都经本人香港个人户；回流内地 **有限制：目前已知中银同名账户可行，待验证**；
- **Mercury = 美元营收**：公司收入、平台结算、公司订阅都在 LLC 名下；
- **Maya = 小额 AI 订阅**：DITO eSIM 收码，虚拟 Visa 付 ChatGPT / Claude 等小额订阅。

### 5.1 按你的情况选

1. 只想付几个海外 AI 订阅：先做 **菲律宾 eSIM + Maya**；
2. 需要人民币稳定进出：安排一次 **赴港开户**；
3. 要做海外产品收款：**注册 LLC → EIN → Mercury**，再用香港户打通出资与回流。

# 细节专题 操作说明

## 06 汇丰香港国际电汇（全球转账）

以下整理汇丰香港网上理财办理国际电汇的一般步骤。页面名称可能因语言或版本略有不同。本专题只整理操作与字段含义，**不含**限额、费率或某一笔交易能否汇出的承诺。

### 6.1 操作步骤

1. 登录汇丰香港网上理财，进入 **「全球转账至其他账户」**；
2. 选择支账账户，并选择新增受款人或已有受款人；
3. 填写受款人姓名、国家／地区、城市、地址，以及银行账户号码或 IBAN；
4. 选择或查询受款银行，核对银行编号、名称和地址；
5. 填写汇款币种、金额、海外费用支付方和汇款目的；
6. 按需要填写备注、给受款银行的信息、给受款人的信息，并选择是否设为经常性转账及转账日期；
7. 仔细核对确认页上的资料，再决定是否提交。

### 6.2 特殊填写提示

下列字段用途不同，填写前先分清。具体格式以受款银行提供的汇款指示及汇丰客服答复为准。

:::table
字段 | 填什么 | 注意
给受款银行的信息 | 如需通过中转行付款，可填写 INTERBANK，后接中转行名称；汇丰客服也表示可填写相应的银行名称或 SWIFT/BIC 等代码 | 具体格式以受款银行汇款指示及汇丰客服答复为准
备注 | 供汇款人参考 | 若设置经常性转账，备注可能显示在受款人的交易记录中，显示方式由受款银行决定
给受款人的信息 | 用于传达付款说明 | 和给受款银行的信息用途不同
银行编号及地址 | 优先核对受款银行提供的国际汇款资料，并确认汇丰页面查询出的银行条目与受款行信息一致 | 美国收款账户可能同时提供 ABA 和 SWIFT/BIC；若页面没有独立的 ABA 输入栏，向汇丰确认是否需要及应填在哪里，不要把 ABA 当作中转行代码
:::

### 6.3 提交前检查

- [ ] 受款人姓名、账户号码／IBAN、国家／地区及地址准确
- [ ] 收款行编号、名称及地址与银行资料相符
- [ ] 如需中转行，已按受款银行指示填写，并确认银行代码或名称格式
- [ ] 金额、币种、费用承担方式、汇款目的及日期正确
- [ ] 确认页没有遗漏或意外变更

:::warn 提交后可能无法修改或取消
汇丰提示，转账确认后可能无法修改或取消。遇到银行地址、ABA 或中转行填写方式不确定时，先向汇丰或收款银行核实，再提交。
:::

:::tip 和三条路线的关系
香港户是人民币枢纽（第 02 章）；向 Mercury 做成员出资时，电汇细节以 Mercury 后台为准，汇丰侧点选与填写按本章执行（第 04 章）。限额、费用、用途证明材料仍以汇丰客服与当时页面为准。
:::
